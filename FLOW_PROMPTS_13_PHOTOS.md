# Flow prompts: the 13 product photos (plus 3 oil packs)

How to use
1. In Flow (Imagen), set the aspect ratio shown for each group. Generate **4 variations** of each prompt and keep the best one.
2. Paste the **Style line** first, then the **Picture line**, then the **Always add** line, as one prompt.
3. Save each as a JPEG with the exact file name shown (for example `product-01.jpg`) in one folder, and send me the folder.
   I crop them to size, place them in all three shop templates and add them to the credits.

**Style line (paste first, every time, so the whole set matches):**
> Professional e-commerce product photograph, soft natural window light from the left, gentle shadow, shallow depth of field, warm neutral palette of ivory, sand and terracotta, clean uncluttered styling, realistic materials and textures, sharp focus, high resolution, shot on a full-frame camera with an 85mm lens.

**Always add (paste last, every time):**
> No text, no letters, no logos, no brand names, no watermark, no people, no hands. Labels are blank and plain.

## Tips
- If text or a logo shows up, add "no text, no letters" again or regenerate. The shop's own name is added by the website, so labels should stay blank.
- Keep the same light direction across a group so the grid looks like one shoot.
- For a real client's shop, they replace these with their own product photos; the file names stay the same.
- AI-generated images are fine for demos. The site's credits page will say so.
